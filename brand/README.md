## 三、使用规范

- **裁切**：一律圆形裁切 + 茶金 2~5px 描边（呼应三端印章元素）
- **底色**：宣纸米白 `#F6F3EC` 圆底，禁止直接放彩色底上
- **最小尺寸**：小程序 120rpx / web 54px，低于此尺寸改用文字印章
- **禁例**：不加滤镜、不拉伸变形、不裁成方形、不改色
